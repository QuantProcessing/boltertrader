# Prerequisites

> Canonical language: English. [Chinese mirror](../zh-CN/getting-started/prerequisites.md)

This page owns what you need installed and decided before
[running the local stack](local-stack.md). Venue credentials are covered by
[Configuration](../reference/configuration.md); what a test run does and does
not prove is covered by [Testing and certification](../reference/testing.md).

## Tools

| Tool | Needed for | Notes |
| --- | --- | --- |
| Docker Engine with the Compose v2 plugin | The whole stack | `make doctor` runs `docker compose version --short`; the plugin is a separate install from the engine |
| Go | `make up`, `make doctor`, `make test`, every acceptance target | `go.mod` declares Go 1.26. Containers build their own Go, so this is only for commands you run outside them |
| Node 22 | `make test-browser` only | The web image builds the frontend itself |
| Git and Make | Everything | Run every command from the repository root |

Confirm the toolchain before anything else:

```sh
go version
docker compose version
make test
```

`make test` is the offline gate — `go test -short ./...`. It reaches no venue,
needs no credentials, and needs no running stack.

## Ports

`make up` publishes five ports, and every one of them binds `127.0.0.1` only.
Nothing in the stack is reachable from another machine.

| Port | Service |
| --- | --- |
| 15432 | PostgreSQL |
| 18080 | Gateway |
| 18090 | Web |
| 18091 | Auth edge |
| 18092 | Trading service |

If one of those is already taken, override it for that command — for example
`POSTGRES_PORT=15433 make up`. The value is written into `.env.stack` and
remembered by `make doctor`, `make logs`, and `make down`.

## The two env files

The repository can hold a `.env` with live venue API credentials. **The stack
never reads it.** Every compose invocation in the `Makefile` passes
`--env-file .env.stack` explicitly:

```make
COMPOSE = docker compose --env-file .env.stack -f compose.yaml
```

Without that flag compose would auto-load `./.env` and inject live credentials
into containers that have no business holding them. `.env.stack` is generated by
`make up`, holds only ports, uids, and paths to secret files, and is ignored by
Git. Do not merge the two, and do not drop the flag from a compose command you
run by hand.

Generated credentials live in `.secrets/test/`, mode `0700`, each file `0600`.
They are ignored by Git and regenerated by `make up` when missing.

## Non-production accounts

Only use credentials issued for the Demo or Testnet environment a page names.
Use a dedicated account, keep it deliberately underfunded, and make sure no
unrelated order or position exists in the product scope a test touches.

Never commit `.env`, never print a credential value, and never pass a secret as
a command argument. See [Configuration](../reference/configuration.md) for the
variable names and which environment each belongs to.

## Keeping writes bounded and serial

External write tests are gated. Run the exact Make target the documentation
names: its recipe enables the write gate for that one process only, and applies
the timeout and no-skip policy the target was defined with. Do not set a write
gate as a persistent shell or file variable, and do not run two external write
targets in parallel.

A run that exits non-zero, times out, or skips leaves final venue state
unconfirmed. Before writing again, resolve it through the product's own identity
and state checks — described in
[Operations and recovery](../guides/operations-recovery.md). Never cancel or
flatten unrelated account state to get back to a clean slate.
