# U3：应用契约迁移

对应[更新计划](update-plan-2026-09-10.md)的 U3。目标是让 Trader 使用独立客户端，
删除重复的 HTTP 行为和浏览器专用同义路径，不增加进程、授权流程或交易所连接。

## 实现

- `services/trading/gateway` 的账户、连接、余额、当前持仓、目录、下单、撤单和恢复
  全部交由 `clients/gateway` 请求与校验。适配层保留 Trading 的命令、成交和持仓模型
  转换，删除自己的 HTTP 请求、响应解码、大小上限、分页循环和令牌副本。
- 新增中立目录 DTO，Gateway 发布方、Go 客户端及内部行情身份解析使用同一组类型。
  独立客户端补齐实际调用方需要的目录和运行就绪读取。
- 账户路由删除 `requestedState`，包括后端、前端、mock、schema 和相应判断。
  路由是否注册与连接是否健康分别由真实记录和连接信息表达。
- 余额改为完整读取，要求 `complete: true`；最多 10,000 条非零余额。超过限制或任意
  路由读取失败就返回错误，分页参数被拒绝。各路由依次读取，不声称跨路由原子快照。
- Trader 选定标的持仓也从完整 `position-snapshot` 过滤；非 live 结果不能变成正常空仓。
- 删除 `/internal/v1/browser/*` 五条路径以及前端未使用的 `/api/v1/catalog/venues`。
  前端目录直接消费 Go 客户端使用的 `{data:{revision,observedAt,instruments}}`；
  行情与 K 线的规范内部端点只接收 `instrumentId`，重复传 venue/product 会被拒绝。
  资金费历史使用已有 `since` / `until` 契约，7/30 天是前端选择的显示窗口。
- 登录、CSRF 和账户增删代理保持原有边界。Gateway 校验服务身份；Trading 不再向
  不读取它的 Gateway 端点发送虚假的用户授权头。账户归属边界由真实 HTTP 登录测试覆盖。

公共 `/v1/market/*` 仍提供按 topic 的能力读取，内部 `market-data` 提供已有聚合展示。
它们共用 Gateway 数据来源与 WS 协议。本批删除的是浏览器独有的重复转接；目录中
交易规则、产品描述和公共发现信息的进一步收敛属于 U5，不以改路径冒充已经完成。

## 交易语义

写请求不重试，未知结果只查询原始订单或幂等键。撤单前先读取订单并核对账户和标的，
失败时不发送 DELETE。成交读取失败保留已收到的订单身份和状态证据，结果继续标为
未知。现有余额、外部持仓和本地成交账务仍是不同来源，不相互重建或替代。

## 验证

- 全仓无凭证短测试：98 个有测试的 Go 包通过，数据库环境设为无效，确保短测不连库。
- 六个关键包 race 通过：独立客户端、Gateway HTTP、Trading 适配层、持仓、手动交易、
  Auth Edge 代理。最后的目录 DTO 清理及 schema/旧路由回归另行运行通过。
- 隔离 PostgreSQL 的真实 Auth Edge → Gateway → Trading 账户链路及 race 通过：
  登录、零余额添加、权限错误、幂等重放、恢复、当前持仓、读取失败、删除和脱敏。
  使用 `/tmp/bolter-u1-postgres.vSgr3R/data`，已关闭，未操作业务数据库。
- 前端 28 个测试文件、192 项测试及生产构建通过。构建仍有已有的主 bundle 体积提示。
- 余额真实 handler + 独立客户端覆盖 0、500、601、10,000、10,001 条余额和分页拒绝。
- 订单身份、未知结果恢复、成交范围、原币种费用、分页中断、错误状态和新增字段回归通过。
- 无凭证 mock 浏览器验证通过：登录、当前持仓显示、非法订单拒绝、合法限价单提交与
  撤销、虚构凭证添加、账户删除；删除后列表从两项变为一项。浏览器与临时前端服务
  已关闭。截图与快照在 `output/playwright/u3/`。这不替代真实交易所验收。
- `git diff --check` 通过。

日志在 `output/architecture-review-2026-09-10/u3-*.log`。
