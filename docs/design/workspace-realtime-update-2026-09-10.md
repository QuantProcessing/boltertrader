# 个人交易工作台与实时反馈改造

状态：2026-09-11 完成。依据用户的四项授权，改造整个工作台、复用浏览器实时连接、修复指数盈亏与订单反馈。视觉参考 [Quiet Workspace](https://gist.github.com/QuantProcessing/1dc0ffb32ce04e92dc966c52c1853ed4)，具体规范见根目录 `design.md`。

## 完成范围

- [x] 单条 `/api/v1/realtime/ws`，复用订阅、取消、心跳、重连和会话隔离。
- [x] 指数价独立订阅；线性仓位精确十进制估值；延迟保留最后值，标记价保持独立。
- [x] 命令响应立即更新订单；持久化订单、成交及相关账本/活动持续推送；账户事件唤醒只读核对。
- [x] 灰绿色工作台、紫色操作强调、侧栏、浅色/深色/系统主题、紧凑指标、宽订单区与窄屏布局。
- [x] Go、前端、数据库、竞态检测和浏览器交互验收；相关中英文使用文档同步。

## 修复的根因

1. 原浏览器按服务归属维护多条连接。现在由 Auth Edge 复用传输，Gateway 仍拥有行情与账户连接，Trading 仍拥有订单与成交身份。没有添加第二套行情缓存或通用事件平台。
2. 标记价格与指数价格混用，过期时清空估值。现在分别保留来源时钟，指数缺失不替换成标记价；行情延迟显示最后数值与延迟标记。盈亏按原币种汇总，未知或反向合约公式保留交易所盈亏。
3. 提交成功后的界面刷新依赖等待 HTTP 核对，终态又依赖定时查询。现在先呈现规范命令响应，Gateway 订单/成交事件提前唤醒 Trading 只读核对，并推送持久化结果。未知交接窗口、租约、幂等键和禁止重发的约束保持不变。
4. 原始 Gateway 订单事件与 Trading 命令身份混用。删除前端旧订单覆盖层，终态不能被较旧 REST 响应退回“已提交”。余额和持仓继续按实体身份、时间及版本合并。
5. 交易表列定义和翻译函数的引用随行情更新变化，导致平仓弹窗被卸载。稳定翻译与列引用后，实时行情到达不再丢失正在填写的表单。
6. 取消订阅晚到确认、重连缓存年龄、WS 预先创建的私有查询缓存和账本恢复存在缺口。现在正确释放订阅、累计报价年龄、退出时清空私有状态；后发 REST 修复可替换旧账本，飞行中的旧响应不能覆盖较新推送。
7. 模拟环境曾只发初始行情、两层 WebSocket 拦截留下空连接。现持续读取公开行情并按生产协议推送；本地模拟成交、撤单、全量平仓也有对应事件。

## 界面调整

交易页保持品种、图表、订单簿和下单票的共同上下文。指标分清最新价、标记价、指数价、日内涨跌、成交量、持仓量和资费。图表保留标记价格线，移除占据视野的文字标签。

持仓主表优先展示账户、方向、数量、开仓均价、指数价和盈亏，保证金/强平价/更新时间放入详情。订单展示状态、成交量/委托量和成交均价。窄屏支持图表/订单簿切换及分区滚动；退出登录时私有数据消失，未知仓位显示为未知，不能显示为零仓位。

- 全仓 `go test -short ./...` 通过，数据库环境显式置为无效值，避免误连本机配置。
- Auth Edge、Trading orders/httpapi、Gateway client、marketowner/httpapi 定向 `-race -short` 通过。
- 独立一次性 PostgreSQL 下 `go test ./services/trading/store/postgres` 通过；新增用例验证只唤醒目标账户的已提交/待成交证据任务，保留其他账户、未知交接窗口与租约。
- 前端 32 个测试文件、212 项测试通过；TypeScript 检查与生产构建通过；浅色与深色文本对比度门禁通过。
- 浏览器检查桌面和 390px 窄屏、主题切换、行情页/持仓/资费/活动/账户表单、单连接订阅释放与重连、登录/退出、模拟市价成交、限价撤单与全量平仓。
- 一次模拟市价确认到显示成交约 0.55 秒；该结果只证明交互链路，不代表真实交易所成交时延。
- 断线验证中，同一仓位的指数价及盈亏保持原值，只增加延迟标记；恢复后重新订阅。平仓弹窗跨一次真实公开指数更新仍保持打开，模拟成交后仓位移除。

## 范围与限制

未使用真实凭证、真实订单或外部通知。浏览器账户/成交为本地模拟，公开行情来自交易所，因此行情数值随运行变化。生产交易所的实际成交时延仍需使用者单独验收。

实时推送针对个人单实例部署；未引入跨实例消息中间件。服务端 30 秒投影修复、前端 60 秒私有快照修复及重连账户重读保留作为恢复机制，不承担正常逐笔更新。构建仍有约 903 KB 主包体积提示，未在本批引入新的打包体系。
